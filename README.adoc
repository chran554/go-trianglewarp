= Triangle Warp

This is an optimized rasterization of a triangle using cpu (no gpu).

The image color/pixel content of the source triangle is rasterized/drawn in a destination image.

== Install

[source, bash]
----
go get github.com/chran554/go-trianglewarp@latest
----

[source, go]
----
import "github.com/chran554/go-trianglewarp"
----

== Usage

To warp a triangular piece of an image to another image simply call `warp.Warp` function.

.Usage of `warp.Warp` function.
[source, go]
----
warp.Warp(srcImage, srcTriangle, dstImage, dstTriangle, warp.InterpolationBiLinear)
----

See also examples below.

== Example

Triangles of image data can be read from a source image and written (distorted) to a destination image.

.Source example for rendering a warped triangle on a destination image.
[source, go]
----
sp1 := image.Point{X: 200, Y: 250}
sp2 := image.Point{X: 400, Y: 250}
sp3 := image.Point{X: 300, Y: 400}

dp1 := image.Point{X: 350, Y: 450}
dp2 := image.Point{X: 500, Y: 350}
dp3 := image.Point{X: 460, Y: 500}

srcTriangle := warp.Triangle{sp1, sp2, sp3}
dstTriangle := warp.Triangle{dp1, dp2, dp3}

warp.Warp(srcImage, srcTriangle, dstImage, dstTriangle, warp.InterpolationBiLinear)
----

== Warp mesh

A convenience method to set up a rectangular mesh of triangles for a rectangle using width and height and number of divisions in width and height.

This rasterization allows for a grid of triangles on the source image to be rendered to a destination image distortedly as the destination triangle grid can be distorted in respect to the source triangle grid.

.Source example for setting up a triangle mesh for an image.
[source, go]
----
	srcImage2, _ := loadImage("images/src-image-2.png")
	dstImage := image.NewRGBA(image.Rect(0, 0, srcWidth, srcHeight))

	xDivisions := 12
	yDivisions := 8

	srcMesh := warp.NewMesh(image.Rect(0, 0, srcWidth, srcHeight), xDivisions, yDivisions)
	dstMesh := warp.NewMesh(image.Rect(0, 0, srcWidth, srcHeight), xDivisions, yDivisions)
